        Cookies

        YouTube, Instagram and TikTok need a sign-in for some content. The browser extension can send the site cookies with every link (setting "Send my cookies"); you can also upload them manually here (Netscape format, cookies.txt). They apply to all downloads; the extension replaces an uploaded file.

        Extension and help

        The extension sends the link of the open tab to this page (with the site cookies, if you allow it in its settings). Chromium browsers: unzip the file, open the extensions page, enable developer mode, "Load unpacked". Firefox keeps unsigned extensions only until restart, see the install guide.
